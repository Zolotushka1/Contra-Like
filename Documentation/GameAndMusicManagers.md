# Игра, пауза и музыка

В сценах Main Menu, Level 1, Level 2, Level 3 и Player Test размещён префаб `Assets/Prefabs/Systems/GameManager.prefab`. Его основной экземпляр сохраняется между сценами; повторные экземпляры автоматически убираются.

## Пауза

Во время игры **Esc** открывает меню паузы. Повторное нажатие Esc или кнопка **Продолжить** возвращает в игру. Кнопка **В меню** открывает карту уровней. В главном меню Esc не ставит игру на паузу.

На паузе останавливаются физика, анимации, игровые таймеры и звуковые эффекты. Музыка продолжает играть. Игровые клавиши, смена оружия и выстрелы заблокированы; нажатие кнопки продолжения не создаёт выстрел или прыжок героя.

Ползунок **Громкость** меняет общий уровень музыки и звуков от 0 до 100%. Значение сохраняется между сценами и запусками игры. Процент рядом с ползунком показывает актуальную настройку. Ползунок работает мышью и стандартной навигацией UI с клавиатуры.

Макет находится в отдельном префабе `Assets/Prefabs/UI/PauseMenu.prefab`: Canvas → Pause Panel → Content. Внутри находятся подписи, Volume Slider, Resume Button и Menu Button. Можно менять внешний вид в Prefab Mode. Кнопки и ползунок уже связаны с публичными методами PauseMenuView; обязательные ссылки вручную назначать не нужно.

## GameManager

`Assets/Scripts/Core/GameManager.cs` отвечает за состояния меню, игры, паузы и загрузки. В Inspector доступны сцена главного меню и события **При постановке на паузу**, **При продолжении игры**. Состояние, таймеры и внутренние ссылки скрыты.

Для подключения других объектов доступны методы **PauseGame**, **ResumeGame**, **TogglePause**, **ReturnToMenu**, **RestartLevel**. События предназначены для дополнительных эффектов; остановка и продолжение игры работают без настройки UnityEvents.

При переходе в меню, перезапуске и загрузке сцены восстановление времени и звука выполняется автоматически. Тестовая клавиша R продолжает перезапускать текущую сцену во время игры; на паузе она не срабатывает.

## MusicManager

Дочерний объект **Music Manager** содержит `Assets/Scripts/Audio/MusicManager.cs` и единственный музыкальный Audio Source. В списке **Музыка сцен** для каждой сцены выбираются основная тема и необязательная тема босса. Включение основной темы при переходе выполняется автоматически.

Назначена уже добавленная музыка: Menu, Level1, Level 2, Level3, Boss 1–3, Titles. В Player Test используется музыка первого уровня.

Для нового уровня добавьте запись в список, выберите сцену из выпадающего меню и назначьте Audio Clip. Поле **Начальная общая громкость** используется при первом запуске; затем действует сохранённый ползунок. В Audio Source можно отдельно настроить громкость музыки относительно звуков, сохранив общий ползунок.

Методы для UnityEvents: **PlayBossMusic** — тема босса текущей сцены; **PlayLevelMusic** — возврат к основной теме; **PlayCreditsMusic** — музыка титров; **PlayMusic(AudioClip)** — указанный трек. Повторный запрос уже звучащей темы не запускает её заново.

GameManager сохраняется как корневой объект со всей своей иерархией. При прямом запуске новой сцены из Editor добавляйте этот префаб и один EventSystem с Input System UI Input Module. В пяти текущих сценах всё уже размещено.
