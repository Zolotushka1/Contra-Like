# Карта уровней

Сцена: `Assets/Scenes/Main Menu.unity`.

```text
Main Menu UI
  Background
  Heading
  Level Manager
    Level 1 Cube
    Level 2 Cube
    Level 3 Cube
  Level Details Window
EventSystem
```

Каждая кнопка — экземпляр `Assets/Prefabs/UI/LevelNode.prefab`.
Фон и карта находятся в `Assets/Prefabs/UI/MainMenuView.prefab`.
Служебный объект отрисовки пунктира скрыт в обычной Hierarchy.

## Настройка уровня

Выберите `Level N Cube`. В компоненте «Уровень на карте» доступны:

- **Название** — подпись под кнопкой.
- **Сцена для загрузки** — выпадающий список включённых сцен из Build Profiles.
- **Картинка параллакса** — PNG с фоном для окна выбора уровня.
- **Описание** — текст в этом окне; длинный текст прокручивается.
- **Открыт с начала игры** — доступность без прохождения предшественников.
- **Следующие уровни** — кнопки, которые откроются после победы.
- **При запуске уровня** и **При открытии уровня** — необязательные UnityEvents
  для звуков и эффектов.

Нажатие на кубик открывает прямоугольное окно поверх карты: фон, описание и
кнопку **Играть**. Крестик, щелчок снаружи и Esc закрывают окно. Щелчок внутри
прямоугольника его не закрывает. После закрытия управление возвращается к карте.

Описания можно смотреть и у закрытых уровней. Кнопка **Играть** у них отключена;
просмотр описания не запускает уровень и не меняет прогресс. Пока окно открыто,
кубики за ним не реагируют на мышь и навигацию с клавиатуры.

Начальная схема: `1 → 2 → 3`. Для запуска доступен только первый уровень.
Для развилки добавьте в «Следующие уровни» первого одновременно второй и третий.
После победы откроются оба. Если к уровню ведут несколько связей, достаточно
победы на любом из его предшественников. Пройденный уровень всегда доступен для
повторного запуска.

Пунктир строится по этим же связям и обновляется при перемещении кнопок,
изменении их размеров, добавлении и удалении связей. Соединение обрывается у
краёв кнопок и не перехватывает клики.

## Добавление уровня

1. Выберите кнопку предшествующего уровня.
2. Нажмите **Создать следующий уровень** в Inspector. Новая кнопка сразу
   добавится внутрь `Level Manager` и свяжется с выбранной. Существующие связи
   сохраняются, поэтому так можно создавать развилки.
3. Выберите сцену новой кнопки, картинку и описание. Для новой сцены сначала
   добавьте её в список сборки в Build Profiles. Окно подключается автоматически:
   отдельное окно для каждого нового уровня создавать не требуется.
4. При необходимости передвиньте кнопку через Rect Transform.

Кнопка «Добавить отдельный уровень» на `Level Manager` создаёт узел без входящих
связей. Свяжите его с предшественником либо откройте с начала игры.
Можно также дублировать существующие кнопки: скрытые идентификаторы автоматически
разделяются. Не изменяйте сцену пройденного узла для создания нового уровня —
создайте отдельный узел, чтобы результаты разных уровней оставались независимыми.

## Победа и сохранение

Карта сохраняет завершённые уровни в `level-progress.json` в
`Application.persistentDataPath`. Открытия вычисляются по актуальной схеме связей,
поэтому новый выход из уже пройденного уровня сразу становится доступен.

Для интеграции победы добавьте компонент **Завершение уровня** (`LevelCompletion`)
на объект игрового уровня. В UnityEvent смерти босса вызовите его метод
**CompleteLevel()**. Он сохраняет победу до вызова события «После победы».
Повторный вызов в одном прохождении не дублирует награду или событие.
В «После победы» можно подключить экран результатов.

Запускайте уровень через карту, чтобы игра знала, какой узел завершён. Пустые
игровые сцены пока не содержат боссов и сами по себе не засчитывают победу.

Цвета состояний и параметры пунктира находятся на `Level Manager`.
Служебные компоненты, ссылки и текущее состояние не вынесены в учебные настройки.

## Оформление окна

Общий макет — `Assets/Prefabs/UI/LevelDetailsWindow.prefab`, вложенный в
MainMenuView. Внутри **Modal** находятся отдельные **Backdrop** и **Window**:
фон закрывает окно по щелчку, а прямоугольник с содержимым перехватывает клики
внутри. В Window размещены Title, Preview, Description, Status, Play Button и
Close Button. Вид и размеры настраиваются в Prefab Mode обычными компонентами UI.

Картинка сохраняет пропорции и заполняет область превью с обрезкой по краям.
Для первого уровня назначен текущий городской фон, для второго и третьего —
кристаллические шпили и астероидное поле из имеющихся параллаксов. Изображения и
тексты каждого уровня можно заменить в компоненте его кубика.

Cube Button вызывает **ShowDetails**, а кнопка Играть —
**LevelDetailsView.PlaySelectedLevel**. Существующий **LevelNode.OpenLevel**
выполняет проверенный запуск выбранного уровня; событие **При запуске уровня**
срабатывает именно при запуске, а не при просмотре карточки.
